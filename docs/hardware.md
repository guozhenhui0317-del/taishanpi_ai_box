# 硬件接线与自检

## 官方 3.1 寸 MIPI 触摸屏

使用官方屏幕扩展板、31P MIPI 排线及 6P 触摸排线。显示采用 MIPI DSI，触摸使用 I²C1，
屏幕须使用官方扩展板的限流背光电路；不要直接接泰山派原板的大屏背光输出。
扬声器与麦克风通过扩展板弹簧针连接泰山派对应触点。

使用适配 3.1 寸屏幕的 Debian 固件，在图形会话中运行 `python3 -m ai_box mipi`。
点击主界面图标进入相应功能；语音和天气页面点击屏幕返回，网络页面使用“返回”按钮。
菜单中的“旋转屏幕”每次将 AI Box 界面旋转 90°，
循环四个方向并同步转换触摸坐标；方向保存在 `/var/lib/ai-box/orientation`，重启后保留。

## SD 卡上的 AI 模型

AI 助手要求 SD 卡挂载到 `/mnt/modelsd`，并使用卡上的 `ollama-models` 和
`vosk-model-small-cn-0.22` 目录。未挂载 SD 卡或缺少模型文件时，进入 AI 助手会显示错误；
天气查询和屏幕旋转功能不依赖 SD 卡。卡重新插入并挂载后，Ollama 服务可能需要几秒钟恢复。
